# Security policy

Inkcast handles sign-in tokens and people's platform credentials, so we take reports seriously.

## Reporting a vulnerability

Use **GitHub private vulnerability reporting**: the repository's Security tab → *Report a vulnerability*. Please include:

- what is affected (version or commit, component, configuration);
- steps to reproduce or a proof of concept;
- impact as you understand it.

Don't open a public issue or pull request for a vulnerability, and don't test against anyone else's deployment or accounts.

## What to expect

| | |
|---|---|
| Acknowledgement | within 3 business days |
| Assessment and plan | within 10 business days |
| Fix | as fast as severity warrants; we'll coordinate a disclosure date with you |

We credit reporters in the advisory unless you prefer otherwise.

## Supported versions

Until 1.0, only the latest release and `main` receive security fixes.
