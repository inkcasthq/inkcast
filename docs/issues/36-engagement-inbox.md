# Engagement inbox (later)

labels: epic:social,later

Read comments and messages on connected accounts; the user's AI assistant drafts replies; a person approves every send, hide and delete through the review screen (issue 35). Official APIs only (Instagram comment scopes, Meta messaging within its reply windows, YouTube `commentThreads`/`comments`). No outbound unsolicited messages, no bulk replies. Safety, minors and legal-threat messages are flagged to a person and never auto-drafted.

Part of the social epic: docs/design/video-platforms-and-review.md
