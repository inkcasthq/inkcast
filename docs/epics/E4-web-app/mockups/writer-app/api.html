API

Everything this page does, you can do from code

Every deployment serves its own reference, with its assets vendored (nothing from a CDN). This page calls the same API.
ReDoc The REST reference to read: every endpoint, its request and response, its errors and the scope it needs. https://inkcast.example.com/api/redoc Read the reference
Swagger UI The same contract, with Try it out: send a call from the browser with your own token. https://inkcast.example.com/api/docs Try it
OpenAPI document The contract as JSON (OpenAPI 3), to generate a typed client. This web app's own client comes from it. https://inkcast.example.com/api/openapi.json Download
MCP server For Claude Code and other MCP clients: the same actions as tools, signed in with OAuth (discovery, registration, PKCE). https://inkcast.example.com/mcp
Send a token in the Authorization header A personal access token carries only the scopes you gave it (Tokens tab). An MCP client's OAuth token carries them all. Tokens and account deletion need an OAuth sign-in: a token can't create or revoke tokens. curl -H "Authorization: Bearer $INKCAST_TOKEN" https://inkcast.example.com/api/v1/posts?days_back=7
Endpoints

What each call does, and the scope a token needs for it

GET /api/v1/me The signed-in user Account any token
POST /api/v1/account/deletion-link One-time link to delete your account Account OAuth sign-in
GET /api/v1/tokens Your personal access tokens Tokens OAuth sign-in
POST /api/v1/tokens Create a personal access token (shown once) Tokens OAuth sign-in
DELETE /api/v1/tokens/{token_id} Revoke a personal access token Tokens OAuth sign-in
GET /api/v1/platforms Platforms and connection status Platforms connections:read
POST /api/v1/platforms/{platform_id}/connect-link One-time link to connect a platform Platforms connections:write
DELETE /api/v1/platforms/{platform_id}/connection Delete stored credentials for a platform Platforms connections:write
GET /api/v1/platforms/{platform_id}/destinations Publications / organizations you can post to Platforms connections:read
POST /api/v1/posts Publish, schedule, draft or preview a story Posts posts:write
GET /api/v1/posts Your posts in a time window Posts posts:read
POST /api/v1/posts/{post_id}/cancel Cancel a scheduled, recovering or unconfirmed post Posts posts:write
POST /api/v1/posts/{post_id}/resend Resend an unconfirmed post as a new one Posts posts:write
POST /api/v1/preview Preview exactly what each platform would receive Posts posts:read
POST /api/v1/stories:sync Publish or update markdown files from a repository Git publishing stories:sync
GET /api/v1/ledger What each synced file became on each platform Git publishing posts:read
GET /api/v1/insights/summary Your publishing numbers for a period Insights insights:read
GET /api/v1/insights/kpis Time series of your KPIs Insights insights:read
