# Inkcast

**Write once in markdown. Publish everywhere — from your AI assistant.**

Inkcast publishes, cross-posts and schedules your writing to Medium, DEV and more, straight from Claude Code or any MCP client. Every copy carries a canonical link back to your blog.

- [inkcast](https://github.com/inkcasthq/inkcast): the server, platform plug-ins and API

Inkcast is source-available under PolyForm Shield, free for your own content. Agencies and products need a commercial licence.
